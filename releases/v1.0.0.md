# naluz/installer v1.0.0 — first release

The global command-line installer for NaluzPHP projects.

```bash
composer global require naluz/installer
naluz new my-app
```

## Highlights

- `naluz new <name>` creates a NaluzPHP project with Composer, generates `APP_KEY` and `JWT_SECRET`, creates the SQLite database
  file, and optionally runs the migrations and initializes Git.
- Options: `--dir`, `--release`, `--dev`, `--name`, `--git`, `--migrate`, `--no-install`, `--no-interaction`.
- Inside a NaluzPHP project, other commands are forwarded to the project's own `naluz` script (`naluz migrate` = `php naluz migrate`).
- Dependency-free; requires PHP 8.2+ and Composer.
- Safe by construction: project name, `--release` and `--name` are validated, programs run without a shell, nothing is ever deleted.

Documentation: https://taliffsss.github.io/naluz-framework-docs/prologue/installer/
